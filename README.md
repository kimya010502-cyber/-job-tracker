# 줍줍 (JOOB)

> 지원하는 오늘이, 더 좋은 내일로.

취준 중 지원 현황을 스프레드시트로 관리하다 한계를 느껴 직접 기획·설계·개발한 개인 프로젝트입니다.
PRD 작성부터 Supabase 기반 DB 설계, AI 도구를 활용한 구현까지 전 과정을 혼자 진행했습니다.

지원한 기업·포지션·전형 진행 상황을 한곳에 기록하고, 전형별 통과율과 지원 추이를 확인하는 개인용 취업 지원 관리 서비스.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 전체 화면 마크업 (로그인, 지원 내역·상세·통계·캘린더·메모·설정·도움말, 공지 모달, 기록 추가 Drawer) |
| `app.js` | 전체 로직 — Supabase 연동, 전형 상태·잠금, 통계 계산, 렌더링 |
| `styles.css` | 디자인 토큰(`:root`)과 전체 스타일 |
| `manifest.json` | PWA 매니페스트 |
| `assets/` | 브랜드 에셋 (가로 로고 / 앱 아이콘 / 마스코트) |
| `supabase/` | DB 스키마와 마이그레이션 SQL |
| `docs/` | 기획 문서 — [통합 PRD](docs/PRD.md)와 [원본 보관함](docs/archive/) |

빌드 도구 없이 정적 파일로 동작한다. 로컬에서는 `index.html`을 정적 서버로 열면 된다.

## 배포

`main` 브랜치 루트를 GitHub Pages가 그대로 서빙한다. **push하면 곧바로 배포된다.**

## 문서

기능 명세·데이터 모델·디자인 기준은 [`docs/PRD.md`](docs/PRD.md) 하나에 정리되어 있다.
시점별 원본 PRD는 [`docs/archive/`](docs/archive/)에 보관한다.
