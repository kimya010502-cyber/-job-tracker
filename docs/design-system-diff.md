| `radius/md` | **8** | 카드, 버튼, 입력, 셀렉트, **모든 칩·배지** |

| 항목 | 현재 → 제안 | 수정 대상 | 이유 |

| v2.4 배지 | **12 → 8** | `1002:506` | pill로 보이지만 높이 18에서 8과 거의 같고, 칩 규칙 하나로 모으는 편이 낫다 |
| 시즌 배지 | **12 → 8** | `1009:703` | 위와 동일 |
