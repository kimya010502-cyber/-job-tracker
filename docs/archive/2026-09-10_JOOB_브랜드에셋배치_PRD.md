# 줍줍(JOOB) 브랜드 에셋 배치 및 화면별 로고 사용 방식 수정 PRD

## 0. 문서 목적

현재 줍줍(JOOB) 서비스에 브랜드 로고를 반영한 상태이지만,
로그인 화면 / 업데이트 공지 모달 / 메인 사이드바에서
로고의 크기, 위치, 중복 노출 방식이 어색하게 적용되어 있어
아래 기준으로 수정한다.

이번 작업은 **전체 UI 리디자인이 아니라 브랜드 에셋 배치 수정**이다.

기존 기능, 데이터 구조, 페이지 레이아웃, 컴포넌트 구조는 최대한 유지하고
로고 / 브랜드명 / 캐치문구의 위치와 크기만 아래 기준에 맞게 정리한다.


영문:
```text
JOOB
```

사이드바 표기:


한 줄형:
```text
지원하는 오늘이, 더 좋은 내일로.
```

# 2. 브랜드 에셋 역할 정의

프로젝트에 아래 3종의 브랜드 에셋을 사용한다.

## 2.1 가로형 메인 로고

구성:
- 마스코트
- 줍줍 한글 로고
- JOOB 영문명
- 캐치 문구 포함

사용 위치:
- 로그인 / 회원가입 화면
- 업데이트 공지 모달
- 소개 / 온보딩 화면

사용하지 않을 위치:
- 메인 사이드바
- 작은 헤더
- 테이블
- 통계 화면

---

## 2.2 정사각형 배경 앱 아이콘

구성:
- 둥근 사각형 배경
- 마스코트
- 별 오브젝트

사용 위치:
- 메인 사이드바 상단
- 모바일 헤더
- favicon
- PWA / app icon

---

## 2.3 배경 없는 마스코트 단독 이미지

사용 위치:
- 빈 상태 화면
- 도움말
- 온보딩
- 로딩 / 안내 일러스트

메인 내비게이션 브랜드 로고로는 사용하지 않는다.

---

# 3. 로그인 화면 수정

## 3.1 현재 문제

현재 로그인 화면의 왼쪽 보라색 소개 영역 상단에
가로형 메인 로고가 **흰색 카드 배경 안에 별도로 삽입**되어 있다.

이로 인해:

- 보라색 배경과 시각적으로 어울리지 않음
- 흰색 박스가 둥둥 떠 보임
- 로고가 작은 크기로 보여 브랜드 존재감이 약함
- 소개 영역과 브랜드 영역의 역할이 중복됨

---

## 3.2 수정 방향

### 왼쪽 소개 영역

왼쪽 보라색 영역에서는 **가로형 메인 로고를 제거한다.**

현재 로고를 감싸고 있는 흰색 카드형 컨테이너도 함께 삭제한다.

왼쪽에는 기존 텍스트 구조만 유지한다.

유지 항목:

- 메인 헤드라인
- 서브 문구
- 캐치 문구
- 핵심 기능 리스트

즉, 왼쪽 영역은
**브랜드 로고 영역이 아니라 서비스 가치 / 기능 소개 영역**으로 사용한다.

---

### 오른쪽 로그인 영역

가로형 메인 로고를
**오른쪽 로그인 / 회원가입 카드 상단에 배치**한다.

권장 구조:

```text
[가로형 줍줍 JOOB 메인 로고]

[로그인 | 회원가입]

[이메일]
[비밀번호]

[로그인 버튼]

[비밀번호를 잊으셨나요?]
```

로고는 로그인 카드 내부 상단 또는 로그인 카드 바로 위에 배치한다.

---

## 3.3 로고 크기

현재보다 확실히 크게 표시한다.

권장:

```text
PC width: 약 220 ~ 280px
height: auto
```

실제 이미지 비율을 유지하면서 조절한다.

로고가 로그인 폼보다 과도하게 크지 않되,
첫 화면에서 브랜드를 바로 인지할 수 있는 수준으로 표시한다.

---

## 3.4 로고 배경

로그인 화면에 가로형 로고를 배치할 때
**추가적인 흰색 카드 / 별도 배경 / 그림자 컨테이너를 만들지 않는다.**

금지:

- 추가 white card
- 별도 rounded container
- shadow box
- border wrapper

로고 에셋 자체만 자연스럽게 배치한다.

---

# 4. 업데이트 공지 모달 수정

## 4.1 현재 문제

업데이트 공지 모달 상단에서:

- 가로형 메인 로고가 너무 작게 표시됨
- 브랜드 인지가 약함
- 로고 자체에 캐치 문구가 포함되어 있는데
  그 아래에 동일 캐치 문구를 다시 노출하고 있어 중복됨

---

## 4.2 가로형 메인 로고 확대

공지 모달 상단 가로형 줍줍 로고를 현재보다 크게 표시한다.

권장:

```text
PC width: 약 180 ~ 240px
height: auto
```

단순한 작은 보조 로고가 아니라
**공지 모달의 브랜드 헤더** 역할을 하도록 한다.

---

## 4.3 중복 캐치 문구 삭제

가로형 메인 로고 아래 별도로 작성된:

```text
지원하는 오늘이, 더 좋은 내일로.
```

문구는 삭제한다.

이유:

가로형 메인 로고 안에 이미 동일 문구가 포함되어 있으므로
동일 메시지를 두 번 반복하지 않는다.

---

## 4.4 공지 모달 상단 최종 구조

```text
[가로형 줍줍 JOOB 메인 로고]

[업데이트 소식]

줍줍(JOOB)으로 새롭게 태어났어요

지원 현황을 가볍게 모아 관리한다는 의미를 담아
줍줍이라는 이름으로 새롭게 단장했어요.

[업데이트 버전 / 업데이트 일시]

[신규 기능 내용]
...
```

로고와 업데이트 제목 사이에 충분한 여백을 둔다.

---

# 5. 메인 화면 사이드바 수정

## 5.1 현재 문제

현재 왼쪽 사이드바에서 브랜드 요소가 두 번 노출되고 있다.

상단:
```text
[작은 아이콘] 줍줍
```

그리고 메뉴 영역 위:
```text
[마스코트 단독 아이콘]
```

이중 노출로 인해:

- 사이드바가 산만해 보임
- 브랜드 계층이 불명확함
- 같은 마스코트가 중복 사용됨

---

## 5.2 메뉴 위 단독 로고 제거

현재 카테고리 메뉴 바로 위에 단독으로 배치된
마스코트 아이콘을 제거한다.

즉, 사이드바 브랜드 영역은 **맨 위 한 곳만 유지**한다.

---

## 5.3 사이드바 상단 브랜드 영역

현재:

```text
[아이콘] 줍줍
```

변경:

```text
[정사각형 배경 앱 아이콘]  줍줍 | JOOB
```

---

## 5.4 사용할 아이콘

사이드바 상단에는
**배경 없는 마스코트 단독 이미지를 사용하지 않는다.**

사용:
```text
정사각형 배경이 포함된 앱 아이콘
```

사용하지 않음:
```text
배경 없는 마스코트 단독 이미지
```

---

## 5.5 아이콘 크기

현재보다 조금 크게 표시한다.

권장:

```text
32px ~ 40px
```

사이드바 높이와 메뉴 간격에 맞춰 자연스럽게 조절한다.

favicon 수준으로 지나치게 작게 사용하지 않는다.

---

## 5.6 서비스명 표기

기존:
```text
줍줍
```

변경:
```text
줍줍 | JOOB
```

권장 스타일:

```text
font-weight: 600 ~ 700
```

한글과 영문명을 별도 줄로 나누지 않고
한 줄 브랜드명으로 표시한다.

# 7. 캐치 문구 사용 규칙

```text
지원하는 오늘이,
더 좋은 내일로.
```

가로형 메인 로고 자체에 이미 캐치 문구가 포함되어 있는 경우
그 바로 아래에서 동일 문구를 반복하지 않는다.

독립 텍스트로 사용 가능한 위치:

- 로그인 소개 영역
- 랜딩
- 온보딩

사용하지 않을 위치:

- 지원 내역 테이블
- 통계
- 사이드바
- 상세 페이지 본문

# 8. 모바일 대응

모바일에서도 브랜드 요소가 깨지지 않도록 한다.

## 로그인

가로형 메인 로고:

```text
max-width: 200 ~ 230px
width: responsive
height: auto
```

로그인 폼과 간격을 충분히 둔다.

## 사이드바 / 모바일 헤더

정사각형 앱 아이콘 사용.

모바일에서 텍스트 공간이 부족한 경우:

```text
[앱 아이콘] 줍줍
```

으로 축약 가능하지만,
PC 사이드바에서는 반드시:

```text
줍줍 | JOOB
```

를 사용한다.

# 9. 절대 변경하지 않을 것

이번 작업에서 아래 영역은 수정하지 않는다.

- 로그인 기능
- 회원가입 기능
- 비밀번호 찾기
- 인증 로직
- 지원 내역 CRUD
- 통계 계산
- 사이드바 메뉴 순서
- 페이지 라우팅
- 업데이트 모달의 동작 로직
- 다시 보지 않기 / 확인했어요 기능
- 데이터 구조
- 전형 상태 로직
- 단계 잠금 로직
- 전체 컬러 시스템
- 전체 레이아웃 구조

이번 작업은 오직:

- 브랜드 에셋 위치
- 브랜드 에셋 크기
- 중복 로고 제거
- 중복 캐치 문구 제거
- 서비스명 표기

를 수정하는 작업이다.

---

# 10. 구현 시 주의사항

1. 이미지 비율을 절대로 왜곡하지 않는다.
2. width 조절 시 height는 auto로 유지한다.
3. 로고 주변에 임의의 카드 / 그림자 / 테두리를 새로 만들지 않는다.
4. 기존 로고 경로를 재사용할 수 있으면 재사용한다.
5. 동일 브랜드 에셋을 같은 화면에 중복 노출하지 않는다.
6. 모바일 / PC 각각에서 배치가 자연스러운지 확인한다.
7. 브랜드 이미지 로딩 실패 시 alt text를 제공한다.
8. 접근성 기준을 해치지 않도록 한다.

- 업데이트 소식 / 제목 / 버전 / 일시 구조 유지

- 정사각형 배경 앱 아이콘 사용

- 서비스명 `줍줍 | JOOB`로 변경

## 공통

- 로고 aspect ratio 유지
- 브랜드 에셋 역할이 화면별로 일관됨
- PC / 모바일 레이아웃 정상
- 기존 기능 영향 없음

# 12. Claude 최종 구현 지시사항

```text
현재 프로젝트에서 브랜드 에셋의 위치와 크기만 수정해줘.

전체 UI 리디자인이나 컴포넌트 리팩터링은 하지 말고
기존 기능, 레이아웃, 컬러 시스템을 최대한 유지해줘.

[로그인]
- 왼쪽 보라색 소개 영역의 가로형 로고와 흰 카드 컨테이너 제거
- 가로형 메인 로고를 오른쪽 로그인 카드 상단으로 이동
- width 약 220~280px
- 추가 카드/배경/그림자 생성 금지

[업데이트 공지]
- 상단 가로형 메인 로고를 width 약 180~240px로 확대

- 기존 업데이트 소식/제목/버전/일시/공지 내용 구조 유지

[사이드바]
- 메뉴 위에 별도로 노출된 마스코트 단독 아이콘 제거
- 최상단 브랜드 영역만 유지
- 기존 배경 없는 아이콘 대신 정사각형 배경 앱 아이콘 사용
- 아이콘 32~40px
- 서비스명을 "줍줍 | JOOB"로 변경

[브랜드 에셋]
- 가로형 로고: 로그인/회원가입/업데이트 공지
- 정사각형 앱 아이콘: 사이드바/모바일 헤더/favicon
- 배경 없는 마스코트: 빈 상태/안내/온보딩에만 사용
```
