비밀번호 변경

전체 삭제

현재 계정의 모든 지원 내역을 삭제합니다. 되돌릴 수 없습니다.

도움말

기본 사용법

  • 우측 상단 "기록 추가"로 새 지원 건을 등록합니다. 기업명, 포지션, 지원일은 필수입니다.
  • 지원 내역 목록에서 기업명을 클릭하면 상세 페이지로 이동합니다.
  • 전형 단계 상태·날짜·메모 등 모든 수정은 상세 페이지에서 이루어집니다.

전형 단계

  • 기본 단계는 서류 → 1차 면접 → 과제 전형 → 임원 면접 → 최종 결과이지만, 자유롭게 이름을 바꾸거나 추가·삭제·순서 변경할 수 있습니다.
  • 상태를 합격/불합격으로 바꾸면 결과일이 오늘 날짜로 자동 기록되며, 언제든 직접 수정할 수 있습니다.

중복 지원 확인

  • 기록 추가 시 동일 기업명을 입력하면 과거 지원 이력이 안내됩니다. 중복이어도 등록은 항상 가능합니다.

합격률 계산

  • 단계별 합격률은 "N번째 전형"을 기준으로, 결과가 확정된(합격/불합격) 건만 분모로 계산합니다. 지원철회 건은 제외됩니다.

비밀번호와 데이터 보관

  • 모든 데이터는 이 브라우저(localStorage)에만 저장되며, 서버로 전송되지 않습니다.
  • 비밀번호는 같은 브라우저 안에서 여러 기록을 구분하는 용도이며 실제 암호화 보안은 아닙니다.
  • 브라우저 데이터 삭제 시 기록도 함께 사라지므로, 설정 메뉴의 "내보내기"로 주기적으로 백업하세요.
